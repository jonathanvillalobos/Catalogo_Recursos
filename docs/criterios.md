# Criterios para clasificar un recurso académico

Para organizar un recurso académico de forma útil, es necesario considerar varios criterios que permitan identificar su valor y contexto.

## 1. Tipo de recurso
Se clasifica según el formato del material, por ejemplo:
- Libro
- Artículo académico
- Video
- Curso
- Presentación
- Documento técnico

## 2. Tema
Debe indicarse la temática principal del recurso, como:
- Matemáticas
- Programación
- Biología
- Historia
- Economía
- Investigación

## 3. Nivel
Indica el grado de dificultad o alcance del contenido:
- Básico
- Intermedio
- Avanzado
- Especializado

## 4. Autor o fuente
Es importante registrar la entidad que generó el recurso:
- Autor individual
- Universidad
- Instituto
- Editorial
- Sitio web oficial
- Organización académica

## 5. Fecha de publicación
Permite evaluar la vigencia y relevancia del recurso en el tiempo.

## 6. Idioma
Identifica el idioma en que está redactado o presentado el contenido.

## 7. Accesibilidad
Evalúa si el recurso puede ser consultado con facilidad por distintos públicos, por ejemplo:
- Acceso libre
- Acceso restringido
- Requiere inscripción
- Compatible con lectura en pantalla
- Incluye subtítulos o transcripciones

## 8. Licencia o derechos de uso
Indica cómo puede reutilizarse el contenido y si se permite uso académico, modificación o distribución:
- Dominio público
- Creative Commons
- Copyright
- Uso libre para fines educativos
- Restricciones de reproducción

Estos criterios ayudan a estructurar el catálogo y a facilitar la búsqueda de materiales adecuados para distintos objetivos académicos.
