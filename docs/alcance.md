# Alcance del proyecto

Este proyecto representa una base inicial para un sistema de catálogo de recursos académicos. Una versión futura podría ampliar la gestión de contenidos, mejorar la búsqueda y facilitar la organización de materiales de estudio.

## Funcionalidades futuras posibles
1. Búsqueda avanzada por palabra clave, autor, tema y nivel académico.
2. Filtros por tipo de recurso, como libro, artículo, video, curso o tutorial.
3. Registro de favoritos y recursos marcados como recomendados o revisados.
4. Clasificación por nivel educativo, desde básico hasta avanzado.
5. Exportación de resultados en formatos como CSV o JSON.
6. Gestión de usuarios con roles para administración y consulta de recursos.

## Objetivo del alcance futuro
La idea es convertir el sistema en una herramienta útil para estudiantes, docentes e investigadores, con una experiencia más completa de organización, búsqueda y consulta de materiales académicos.
